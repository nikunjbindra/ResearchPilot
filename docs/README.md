## Milestone 2 PDF Submission Checklist

Before submitting the form, place your exported Milestone 2 report PDF here:

- **Filename format:** `M2_<TeamID>_<ProjectTitle>.pdf` (e.g., `M2_T23_ResearchPilot.pdf`)
- **Max file size:** 10 MB
- **Required sections (in order):**
  1. Cover page (Team ID, team name, project title, batch, faculty name, all members + enrollment numbers, 3 links)
  2. Prompt and solution design (problem description, diagrams, prompt sheets)
  3. Implementation (built modules status table, prompt iteration log v1–v3)
  4. Demonstration and testing (test table with >=10 inputs and >=3 edge cases, screenshots of real runs, limitations)
  5. Repository (screenshot of repo and 3–5 lines on changes since Milestone 1)
  6. Supporting document (Technical report / BMC / Abstract)
  7. Team contribution table
